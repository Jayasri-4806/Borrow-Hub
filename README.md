# 🚀 RentX – Online Rental Management System

## 📌 Project Overview

RentX is a web-based Rental Management System developed using React.js. This application provides a simple and convenient platform for users to browse, select, and rent different types of products.

Nowadays, many people need products for a short period but do not want to purchase them permanently. For example, students may need laptops for projects, photographers may need cameras for events, and travelers may need camping equipment for trips.

RentX helps solve this problem by providing a platform where users can explore different rental products, view product details, select rental durations, choose additional accessories, and calculate the total rental cost.

The main objective of this project is to make the rental process simple, user-friendly, and convenient.

**Project Type:** Frontend Web Application

---

## 🎯 Project Objectives

The main objectives of RentX are:

- To provide an easy-to-use online rental platform.
- To allow users to browse different categories of rental products.
- To display detailed information about each product.
- To allow users to select rental periods.
- To provide optional accessories for rental products.
- To calculate rental costs based on selected products and rental duration.
- To manage booking details and rental history.
- To improve the overall user experience through a simple and attractive interface.

---

## ✨ Features and Functionalities

### 1. User Registration and Login

- Users can register by providing the required details.
- Existing users can access the login page.
- Provides a simple interface for user access.

### 2. Home Page

- Displays the main introduction of the RentX application.
- Provides navigation to different sections.
- Helps users explore available rental categories.

### 3. Product Browsing

Users can explore different products available for rent.

Product categories include:

- Laptops
- Cameras
- Camping Tents
- Gaming and other rental products

Each category provides access to its corresponding product details page.

### 4. Product Details

- Displays product information.
- Shows the rental price.
- Provides information about available accessories.
- Allows users to select additional items.

### 5. Rental Booking

- Users can select the rental start date.
- Users can choose the return date.
- Users can select the rental duration.
- The application calculates the total rental amount.
- Users can confirm their booking.
- Date validation helps prevent invalid rental dates.

### 6. Accessories Selection

Users can select additional accessories based on their requirements.

Examples:

**Laptop Accessories:**
- Wireless Mouse
- Laptop Bag
- Wireless Keyboard
- Laptop Stand

**Camera Accessories:**
- Tripod
- Camera Bag
- Memory Card
- Extra Battery

**Camping Accessories:**
- Sleeping Bag
- Camping Lantern
- Camping Chair

The selected accessories are included in the rental cost calculation.

### 7. My Rentals

- Displays the user's booking information.
- Shows previously created rental bookings.
- Helps users view their rental details.
- Displays rental status.

### 8. Wishlist

- Allows users to save their favourite products.
- Helps users access selected products later.
- Provides an easy way to manage interested products.

### 9. Dashboard

- Displays relevant rental information.
- Provides access to booking details.
- Includes wishlist and recently viewed product information.

### 10. Local Storage

- Uses browser Local Storage to maintain selected application data.
- Stores booking information.
- Maintains wishlist information.
- Helps preserve relevant data after refreshing the page.

## 🛠️ Technologies Used

### Frontend Technologies

**HTML5**
- Used to create the structure of web pages.
- Provides the basic elements of the application.

**CSS3**
- Used to design and style the application.
- Provides colours, layouts, spacing, animations, and responsive styling.

**JavaScript**
- Used to implement application logic.
- Handles calculations, validations, and user interactions.

**React.js**
- Used to develop reusable UI components.
- Manages application state and dynamic content.
- Helps build a single-page application.

**React Router DOM**
- Used for navigation between different pages.
- Helps manage application routes.

**Browser Local Storage**
- Used to store booking and wishlist data in the browser.

## ⚙️ Application Workflow

1. The user opens the RentX application.
2. The user explores the available product categories.
3. The user selects a product.
4. The application displays the product details and rental price.
5. The user selects the required accessories.
6. The user chooses the rental start date and return date.
7. The application calculates the total rental amount.
8. The user confirms the booking.
9. The booking information is stored in Local Storage.
10. The user can view booking information in the My Rentals section.

## 💻 Installation and Setup

Follow these steps to run the project on your local computer.

### Step 1: Clone the Repository

```bash
git clone https://github.com/Jayasri-4806/Borrow-Hub.git
```

### Step 2: Navigate to the Project Folder

```bash
cd Borrow-Hub
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Start the Development Server

```bash
npm run dev
```

### Step 5: Open the Application

Open the local development URL displayed in the terminal in your web browser.
